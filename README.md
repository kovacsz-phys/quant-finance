# Quantitative Finance Library

A modern C++20 library for quantitative finance, numerical methods, and financial derivatives pricing.

The project aims to provide efficient, well-tested implementations of fundamental quantitative finance models, with particular emphasis on numerical accuracy, software design, and computational performance.

It is being developed as a portfolio project demonstrating modern C++ programming, mathematical modelling, numerical computation, and software engineering practices relevant to quantitative development.

## Current Features

### Black–Scholes Option Pricing

The library currently implements analytical pricing of European call and put options using the Black–Scholes model.

Supported functionality:

- European call option pricing
- European put option pricing
- Standard normal cumulative distribution function
- Put–call parity verification
- Input validation and error handling

### Mathematical Model

For a non-dividend-paying underlying asset, the Black–Scholes price of a European call option is

\[
C = S N(d_1) - K e^{-rT}N(d_2),
\]

and the price of a European put option is

\[
P = K e^{-rT}N(-d_2) - S N(-d_1),
\]

where

\[
d_1 =
\frac{\ln(S/K)+(r+\sigma^2/2)T}
{\sigma\sqrt{T}},
\]

\[
d_2 = d_1-\sigma\sqrt{T}.
\]

Here:

| Symbol | Description |
|---|---|
| \(S\) | Current underlying asset price |
| \(K\) | Option strike price |
| \(r\) | Continuously compounded risk-free interest rate |
| \(\sigma\) | Annualized volatility |
| \(T\) | Time to maturity in years |
| \(N(x)\) | Standard normal cumulative distribution function |

The implementation uses the complementary error function (`std::erfc`) from the C++ standard library to evaluate the normal cumulative distribution function.

The implementation currently assumes positive spot price, strike price, volatility, and time to maturity. The interest rate may be negative.

## Requirements

The following tools and libraries are required:

- C++20-compatible compiler (GCC or Clang)
- CMake 3.20 or newer
- Ninja
- Google Test

On Ubuntu, the dependencies can be installed using:

```bash
sudo apt update

sudo apt install -y \
    build-essential \
    cmake \
    ninja-build \
    libgtest-dev
```

## Building the Project

Clone the repository:

```bash
git clone https://github.com/kovacsz-phys/quant-finance.git

cd quant-finance
```

Configure the project:

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
```

Compile:

```bash
cmake --build build
```

Run the example application:

```bash
./build/option_pricing
```

## Running the Tests

The project uses Google Test for unit testing.

Run the complete test suite with:

```bash
ctest --test-dir build --output-on-failure
```

The current test suite verifies:

- European call option pricing against a known reference value
- European put option pricing against a known reference value
- Put–call parity
- Rejection of invalid spot prices
- Rejection of invalid volatility values

The current test suite contains five unit tests, all of which pass successfully.

The model produces approximately:

| Result | Option price |
|---|---:|
| European call | 10.450584 |
| European put | 5.573526 |

The implementation also verifies put–call parity:

\[
C-P=S-Ke^{-rT}.
\]

## Development Roadmap

The following features are planned for future development:

- **Option Greeks:** Analytical calculation of Delta, Gamma, Vega, Theta, and Rho.
- **Implied Volatility:** Numerical estimation using root-finding algorithms.
- **Binomial Option Pricing:** Discrete-time option pricing models.
- **Monte Carlo Simulation:** Simulation-based valuation of financial derivatives.
- **Numerical Methods:** Convergence analysis, numerical stability, and error estimation.
- **Performance Benchmarking:** Computational performance and algorithmic efficiency.
- **Python Integration:** Python bindings for quantitative analysis and experimentation.
- **Continuous Integration:** Automated compilation and testing using GitHub Actions.

## Project Goals

The long-term objective is to develop a modular quantitative finance library demonstrating:

- Modern C++ programming and object-oriented design
- Numerical algorithms and computational mathematics
- Financial derivatives modelling
- Software testing and validation
- Performance-oriented implementation
- Integration between C++ and Python

The project is intended as an educational and technical portfolio demonstrating skills relevant to quantitative software development and financial engineering.
